## Funktionen

| Kategorie | Beschreibung |
|-----------|--------------|
| **Serververbindung** | Verbindung zu jedem Minecraft-Server |
| **Bewegungskontrolle** | Gehen, Springen, Rennen, Schwimmen, Navigation |
| **Kampfsystem** | Entity-Angriffe, Waffen und Rüstungen |
| **Gegenstandsverwaltung** | Inventar, Gegenstände bewegen, Ausrüsten |
| **Synthese** | Synthese via Inventar/Werkbank |
| **Schmelzen** | Erze im Ofen schmelzen |
| **Container** | Truhen, Trichter, Spender |
| **Handel** | Handel mit Dorfbewohnern |
| **Landwirtschaft** | Pflügen, Pflanzen, Ernten |
| **Bauen** | Bauen per Blueprint |
| **Visuell** | Screenshots und Informationen |
| **Wiki** | Rezepte/Informationen abrufen |

## Schnellstart

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install

node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline
```
