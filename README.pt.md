## Funcionalidades

| Categoria | Descrição |
|-----------|-----------|
| **Conexão servidor** | Conexão com qualquer servidor Minecraft |
| **Controle movimento** | Andar, pular, correr, nadar, navegação |
| **Sistema combate** | Ataque a entidades, armas e armaduras |
| **Gestão itens** | Inventário, mover itens, equipar |
| **Síntese** | Síntese via inventário/bancada |
| **Fundição** | Fundir minérios no forno |
| **Contentores** | Baús, funis, dispensador |
| **Comércio** | Comércio com aldeões |
| **Agricultura** | Arar, plantar, colher |
| **Construção** | Construção por blueprint |
| **Visual** | Capturas de tela e informações |
| **Wiki** | Consultar receitas/informações |

## Início rápido

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install

node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline
```
