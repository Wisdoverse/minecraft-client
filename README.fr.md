## Fonctionnalités

| Catégorie | Description |
|-----------|-------------|
| **Connexion serveur** | Connexion à tout serveur Minecraft |
| **Contrôle mouvement** | Marche, saut, sprint, natation, navigation |
| **Système de combat** | Attaque d'entités, armes et armures |
| **Gestion items** | Inventaire, déplacement, équipement |
| **Synthèse** | Synthèse via inventaire/établi |
| **Fonte** | Fonte de minerais au four |
| **Conteneurs** | Coffres, entonnoirs, distributeur |
| **Commerce** | Commerce avec villageois |
| **Agriculture** | Labour, plantation, récolte |
| **Construction** | Construction par blueprint |
| **Visuel** | Captures d'écran et informations |
| **Wiki** | Consulta de recetas/informaciones |

## Démarrage rapide

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install

node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline
```
