## Функции

### Мониторинг в реальном времени

- **Отслеживание агентов** — Отслеживайте положение, здоровье, инвентарь и статус агентов в реальном времени
- **Поток событий** — Передавайте все события агентов на платформу наблюдения
- **Снимки мира** — Периодические снимки блоков и сущностей вокруг агентов

### Встроенные инструменты

- **Поиск пути** — Навигация к любому месту с помощью A*
- **Бой** — Атака сущностей с настраиваемым поведением
- **Инвентарь** — Полное управление инвентарём (перемещение, экипировка, выброс предметов)
- **Крафт** — Создание предметов за верстаком или в инвентаре
- **Плавка** — Плавка руды и приготовление пищи
- **Сельское хозяйство** — Автоматическое выращивание культур (пшеница, морковь, картофель, свёкла)
- **Строительство** — Строительство конструкций из файлов чертежей
- **Торговля** — Торговля с жителями
- **Сон** — Найти кровать и спать
- **Рыбалка** — Автоматическая рыбалка

### Платформа наблюдения

- **WebSocket соединение** — Двусторонняя связь в реальном времени
- **Подписка на события** — Подписка на определённые типы событий
- **Командная координация** — Поддержка нескольких агентов
- **Отчёты о прогрессе** — Отслеживание прогресса строительства

## Быстрый старт

### Требования

- Node.js 18+
- Minecraft сервер (Java Edition 1.8+)

### Установка

```bash
git clone https://github.com/Wisdoverse/mineworld.git
cd mineworld
npm install
npm run dev
```

## Наблюдаемость

### Типы событий

| Событие | Описание |
|---------|----------|
| `connected` | Агент подключился к серверу |
| `disconnected` | Агент отключился |
| `moved` | Агент переместился |
| `jumped` | Агент прыгнул |
| `attacked` | Агент атаковал сущность |
| `damaged` | Агент получил урон |
| `died` | Агент умер |
| `chat_sent` | Отправлено сообщение |
| `chat_received` | Получено сообщение |
| `block_broken` | Блок сломан |
| `block_placed` | Блок установлен |
| `item_picked_up` | Предмет подобран |
| `item_dropped` | Предмет выброшен |
| `inventory_changed` | Инвентарь изменён |
