## Функции

| Категория | Описание |
|-----------|----------|
| **Подключение к серверу** | Подключение к любому серверу Minecraft |
| **Контроль движения** | Ходьба, прыжки, бег, плавание, навигация |
| **Боевая система** | Атака сущностей, оружие и броня |
| **Управление предметами** | Инвентарь, перемещение, экипировка |
| **Синтез** | Синтез через инвентарь/верстак |
| **Плавка** | Плавка руды в печи |
| **Контейнеры** | Сундуки, воронки, раздатчики |
| **Торговля** | Торговля с жителями |
| **Сельское хозяйство** | Вспахивание, посадка, сбор урожая |
| **Строительство** | Строительство по чертежам |
| **Визуал** | Скриншоты и информация |
| **Wiki** | Поиск рецептов/информации |

## Быстрый старт

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install

node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline
```
