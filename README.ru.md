## Функции

### Основные возможности

| Категория | Описание |
|-----------|-------------|
| **Подключение к серверу** | Подключение к любому Minecraft серверу (офлайн или онлайн) |
| **Контроль движения** | Ходьба, прыжки, бег, плавание, навигация с pathfinder |
| **Боевая система** | Атака сущностей, использование оружия и брони |
| **Управление предметами** | Просмотр инвентаря, перемещение предметов, управление экипировкой |
| **Система крафта** | Создание через инвентарь или верстак |
| **Система плавки** | Плавка руды с автоматическим обнаружением печи |
| **Операции с контейнерами** | Сундук, воронка, дроппер, диспенсер, бочка, печь |
| **Торговая система** | Интерфейс торговли с жителями |
| **Сельскохозяйственная система** | Автоматическая вспашка, посадка, сбор урожая |
| **Система строительства** | Строительство по чертежам, отчет о прогрессе |
| **Система визуализации** | Снимок экрана и информация о сцене |
| **Запрос Wiki** | Поиск рецептов и информации в Minecraft Wiki |

### Расширенные функции

| Функция | Описание |
|---------|-------------|
| **Управление транспортом** | Вход/выход из лодки и вагонетки |
| **Блокировка щитом** | Включение/выключение блокировки щитом |
| **Белый список дропа** | Защита важных предметов от случайного выброса |
| **Авто-экипировка** | Автоматическое надевание созданной брони, щитов, луков |
| **Очистка печи** | Извлечение всего содержимого печи одним кликом |
| **Мульти-контейнер** | Автоматическое определение типа контейнера |

## Быстрый старт

### Установка

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install
```

### Подключение к серверу

```bash
# Офлайн сервер (по умолчанию)
node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline

# С платформой наблюдения
node scripts/connect.js --host localhost --port 25565 --username MyBot \
  --observer-ws "wss://your-observer-server/ws/agent" \
  --observer-token "your-token"
```

## Поддерживаемые действия

| Действие | Описание |
|----------|-------------|
| `move` | Движение в направлении |
| `jump` | Прыжок |
| `chat` | Отправить сообщение |
| `attack` | Атаковать сущность |
| `craft` | Создать предмет |
| `smelt` | Переплавить предмет |
| `chest` | Операции с контейнерами |
| `boat` | Вход/выход из лодки |
| `block` | Блокировка щитом |

## События платформы

| Событие | Описание |
|---------|-------------|
| `connected` | Бот подключен |
| `moved` | Бот перемещен |
| `attacked` | Бот атаковал |
| `item_picked_up` | Предмет подобран |
