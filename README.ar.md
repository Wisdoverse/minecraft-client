## الميزات

### القدرات الرئيسية

| الفئة | الوصف |
|-------|-------|
| **الاتصال بالخادم** | الاتصال بأي خادم Minecraft (غير متصل أو متصل) |
| **التحكم بالحركة** | المشي، القفز، الركض، السباحة، التنقل مع pathfinder |
| **نظام القتال** | مهاجمة الكيانات، استخدام الأسلحة والدروع |
| **إدارة العناصر** | عرض المخزون، نقل العناصر، إدارة المعدات |
| **نظام التصنيع** | التصنيع باستخدام المخزون أو طاولة العمل |
| **نظام الصهر** | صهر الخامات مع الكشف التلقائي عن الفرن |
| **عمليات الحاويات** | الصندوق، القمع، موزع العناصر، البرميل، الفرن |
| **نظام التجارة** | واجهة التجارة مع السكان |
| **نظام الزراعة** | الحراثة، الزراعة، الحصاد تلقائياً |
| **نظام البناء** | البناء بالرسومات، تقرير التقدم |
| **نظام الرؤية** | لقطة شاشة ومعلومات المشهد |
| **استعلام ويكي** | البحث عن الوصفات والمعلومات في ويكي Minecraft |

### الميزات المتقدمة

| الميزة | الوصف |
|--------|-------|
| **التحكم بالمركبات** | الدخول/الخروج من القارب والعربة |
| **حظر الدرع** | تفعيل/إلغاء حظر الدرع |
| **قائمة بيضاء للإسقاط** | حماية العناصر المهمة من الإسقاط العرضي |
| **التجهيز التلقائي** | تجهيز الدروع والأقواس والدروق المصنوعة تلقائياً |
| **تفريغ الفرن** | سحب كل محتويات الفرن بنقرة واحدة |
| **حاويات متعددة** | الكشف التلقائي عن نوع الحاوية |

## البدء السريع

### التثبيت

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install
```

### الاتصال بالخادم

```bash
# خادم غير متصل (افتراضي)
node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline

# مع منصة المراقبة
node scripts/connect.js --host localhost --port 25565 --username MyBot \
  --observer-ws "wss://your-observer-server/ws/agent" \
  --observer-token "your-token"
```

| الإجراء | الوصف |
|---------|-------|
| `move` | التحرك في الاتجاه |

| `chest` | عمليات الحاويات |
