## الميزات

| الفئة | الوصف |
|-------|-------|
| **اتصال الخادم** | الاتصال بأي خادم Minecraft |
| **التحكم في الحركة** | المشي، القفز، الركض، السباحة، الملاحة |
| **نظام القتال** | هجوم الكيانات، الأسلحة والدروع |
| **إدارة العناصر** | الجرد، نقل العناصر، التجهيز |
| **نظام التصنيع** | التصنيع عبر الجرد/طاولة العمل |
| **النظام** | صهر الخامات في الفرن |
| **الحاويات** | الصناديق، القمع، الموزع |
| **نظام التجارة** | التجارة مع villagers |
| **نظام الزراعة** | الحراثة، الزراعة، الحصاد |
| **نظام البناء** | البناء عبر blueprints |
| **النظام البصري** | لقطات الشاشة والمعلومات |
| **ويكي** | البحث عن الوصفات/المعلومات |

## البدء السريع

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install

node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline
```
