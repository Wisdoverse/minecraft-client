## 기능

| 카테고리 | 설명 |
|---------|------|
| **서버 연결** | 모든 Minecraft 서버에 연결 |
| **이동 제어** | 걷기, 점프, 전력질주, 수영, 경로 탐색 |
| **전투 시스템** | 엔티티 공격, 무기/방어구 사용 |
| **아이템 관리** | 인벤토리 확인, 아이템 이동, 장비 관리 |
| **합성 시스템** | 인벤토리/작업대 합성 |
| **제련 시스템** | 용광로에서 광석 제련 |
| **컨테이너 조작** | 상자, 호퍼, 드로퍼, 디스펜서 |
| **거래 시스템** | 주민과 거래 |
| **농업 시스템** | 자동 경작, 작물 심기, 수확 |
| **건축 시스템** | 청사진 건설 |
| **시각 시스템** | 스크린샷 및 정보 가져오기 |
| **Wiki 조회** | Minecraft Wiki에서 레시피/정보 조회 |

## 빠른 시작

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install

# 서버에 연결
node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline
```
