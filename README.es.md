## Características

| Categoría | Descripción |
|-----------|-------------|
| **Conexión servidor** | Conexión a cualquier servidor Minecraft |
| **Control movimiento** | Caminar, saltar, correr, nadar, navegación |
| **Sistema combate** | Ataque a entidades, armas y armaduras |
| **Gestión items** | Inventario, mover items, equipar |
| **Síntesis** | Síntesis via inventario/mesa de trabajo |
| **Fundición** | Fundir minerales en horno |
| **Contenedores** | Cofres, tolvas, dispensador |
| **Comercio** | Comercio con aldeanos |
| **Agricultura** | Arar, plantar, cosechar |
| **Construcción** | Construcción por blueprint |
| **Visual** | Capturas de pantalla e información |
| **Wiki** | Consulta de recetas/informaciones |

## Inicio rápido

```bash
git clone https://github.com/Wisdoverse/minecraft-client.git
cd minecraft-client
npm install

node scripts/connect.js --host localhost --port 25565 --username MyBot --auth offline
```
